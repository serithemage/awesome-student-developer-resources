## AIコーディングツール

- 🆓 [GitHub Copilot Free](https://github.com/features/copilot) - GitHubが提供するAIコーディングアシスタントです。無料プランで月2,000回のコード補完と一定量のチャットが利用でき、GitHub Student Developer Pack認証済みの学生はGitHub Copilot Studentプランを無料で利用できます。日本からの申請: 申請可能 — GitHub Educationは世界中で無料で利用でき、在学証明と学校発行のメールアドレスまたは在学確認書類が必要です。[GitHub Education](https://github.com/education)
- 🆓 [Cursor Free Plan](https://www.cursor.com/) - AIコーディングエージェント兼エディタです。Freeプランは月$0で、限られたagentリクエストとChatリクエストを利用でき、有料プランはPlusの月$8からです。価格に税は含まれず、サードパーティモデルの利用料は別途請求されます。
- 🎓 [Zed Education](https://zed.dev/education) - 18歳以上の大学在学生にZed Proを1年間無料で提供します。月$10相当のAIトークンクレジットと無制限のedit predictionが含まれます。作成から30日以上経過したGitHubアカウントと大学のメールアドレスで認証し、1年後はFreeプランに移行します。日本からの申請: 申請可能 — 公式FAQは世界中の認定大学の在学生を対象とし、18歳以上・作成から30日以上経過したGitHubアカウント・現行の大学メールが必要です。[Zed Education](https://zed.dev/education)
- 🎓 [OpenAI Codex Student Credits](https://developers.openai.com/community/students) - OpenAIのコーディングエージェントCodexに使える$100相当(2,500クレジット)のChatGPTクレジットを提供します。発行後12か月有効、1人1回で、米国・カナダ在住の学位課程の大学生がSheerID認証で受け取れます。日本からの申請: 不可 — 米国・カナダの学位授与大学の在学生で、申請時に米国・カナダに居住している必要があり、日本は対象に含まれません。[公式学生ページ](https://developers.openai.com/community/students)
- 🎓 [Kiro for Students](https://kiro.dev/students/) - AWSが提供するAIコーディングエージェントです。コード生成、デバッグ、最適化をサポートし、AWSサービスとの統合が強みです。参加大学の18歳以上の学生は12か月間、毎月1,000クレジットを無料で受け取り、プレミアムモデル、Kiro Web、Kiro Crewなどの有料機能を利用できます。クレジットカードは不要ですが、未使用クレジットは繰り越されず、特典期間中は追加クレジットを購入できません。参加大学のメールアドレスでSheerID認証を行います。日本からの申請: 条件付き — 公式の参加大学リストに載る日本の大学はKobe University、The University of Tokyo、Tohoku Universityの3校のみで、18歳以上・参加大学のメールアドレス・SheerID認証が必要です。[参加大学](https://kiro.dev/students/) · [規約](https://kiro.dev/students/terms/)
- 🆓 [Continue.dev](https://www.continue.dev/) - VS Code、JetBrains IDE、CLIをサポートするオープンソースのAIコーディングエージェントです。Cursorに買収されましたが、オープンソースのコードベースは引き続き無料で公開されています。
- 🆓 [Google Antigravity](https://antigravity.google/) - 自律エージェントでソフトウェアを構築するGoogleのエージェントファーストIDEです。無料のIndividualプランは月$0で、多様なエージェントモデル、無制限のTab補完、無制限のコマンドリクエスト、基本的な週次利用上限を提供します。対応国・地域に関連付けられた個人のGoogleアカウントが必要で、18歳以上が対象です。
- 🎓 [Mistral Vibe Education Plan](https://mistral.ai/pricing/) - 認証済みの学生はMistral Pro(Education)プランを月$14.99ではなく$5.99で利用できます。コーディングや長時間タスクのためのVibeの全機能、高い利用上限、APIクレジット、チャット・メールサポートが含まれます。日本からの申請: 確認不可 — 公式価格ページは世界共通のUSD価格と「認証済み学生」の条件のみを示し、対象国や日本のメール要件を提示していません。
- 🎓 [TinyFish Student Program](https://www.tinyfish.ai/students) - 世界中の在学学生が参加でき、対象の学術メールアドレスで登録するとTinyFishウォレットクレジット$35を受け取れます。Bounty Board、承認されたビルドへのギフトカード、学生コミュニティのオフィスアワー、リーダーボードも利用できます。日本からの申請: 申請可能 — 世界中の在学学生が参加できますが、公開されている対象ドメインに.ac.jpが含まれないため、community@tinyfish.aiへ審査を依頼する必要がある場合があります。[公式学生ページ](https://www.tinyfish.ai/students)

- 🎓 [Claude for Education](https://www.anthropic.com/education) - AnthropicのClaude for Educationは、高等教育に特化したClaudeを提供します。ガイド付き学習のためのLearning mode、学生プロジェクト向けのAPIクレジット、多数の大学とのパートナーシップが含まれます。教育機関はAnthropicに連絡してキャンパス全体のアクセスをリクエストできます。日本からの申請: 条件付き — 大学がAnthropicとキャンパス全体の契約を結ぶ必要があり、公式ページに日本の提携大学がないため、所属大学の導入状況を確認してください。[Claude for Education](https://www.anthropic.com/education)

- 🎓 [Perplexity Education Pro](https://www.perplexity.ai/students) - 大学以上の在学生・教職員にPerplexity Proを50%割引($10/月)で提供します。Learn Modeなどの教育機能が含まれ、SheerIDで認証します。日本からの申請: 確認不可 — 公式の学生ページやヘルプページに対象国、日本価格、現地条件の記載がなく、SheerIDが日本の学校に対応しているかも確認できません。
- 🆓 [StudyArena](https://studyarena.com) - 学習の質問に対する3つのモデルの回答を匿名で比較し、投票後にどのモデルだったかを確認できる無料ツールです。無料アカウント（Google・Apple・Discord・メール）があれば使え、学生認証は不要です。モデルの指定と6つの回答の比較には有料プラン「Supporter」（月額$20）が必要です。

## コントリビュート

コントリビュートを歓迎します!項目を追加する際は:

- `- 🎓 [プログラム名](URL) - 説明` の形式を使用します(学生・教育機関の認証が必要なら🎓、誰でも無料なら🆓)。
- 公式ページに基づき、特典の具体的な内容(割引率、クレジット金額、期間)と資格・認証方法を含めます。
- 内容に合う既存のセクションに配置し、合うセクションがない場合のみ新しいセクションを追加します。
- 3つの言語ファイルをすべて更新します: `README.md`(英語)、`README.ko.md`(韓国語)、`README.ja.md`(日本語)。
