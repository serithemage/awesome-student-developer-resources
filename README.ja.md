## バイブコーディング・AIアプリビルダー

- 🎓 [Replit Student Discount](https://replit.com/edu/students) - 学生にReplit Coreプランを50%割引($10/月)で提供します。自然言語からアプリを構築・デプロイするReplit AgentのAIクレジットが含まれます。.eduメールアドレスで認証します。
- 🎓 [Lovable for Students](https://lovable.dev/students) - Lovable Proプランを最大12か月間50%割引($12.50/月)で提供します。世界中の認定大学の在学生が対象で、大学のメールアドレスまたは学生証で認証します。Freeプランからのみ有効化でき、解約すると再有効化できません。
- 🎓 [Bolt.new Education Discount](https://bolt.new/education-discount) - 大学・高等教育機関の学生にBolt Proの50%割引を提供します(教師はPro無料)。SheerID認証後にクーポンコードが発行され、K-12は対象外です。
- 🎓 [v0 for Students (Vercel)](https://v0.app/students) - プロンプトからフルスタックアプリを生成するVercelのAIアプリビルダーv0のPremiumプランを1年間無料で提供します。パートナー校(Stanford、MIT、Berkeley、Georgia Tech、Waterlooなど)限定で、学校のメールアドレスで登録・認証します。

## AIコーディングツール

- 🆓 [GitHub Copilot Free](https://github.com/features/copilot) - GitHubが提供するAIコーディングアシスタントです。無料プランで月2,000回のコード補完と50回のチャットが利用でき、GitHub Student Developer Pack認証済みの学生はGitHub Copilot Proを無料で利用できます。
- 🆓 [Cursor Free Plan](https://www.cursor.com/) - AIベースのコードエディタで、無料プランでは月50回のプレミアムAIリクエストとマルチファイル編集機能を提供します。VS Codeベースなので、慣れた環境でAIコーディングを体験できます。
- 🎓 [Zed Education](https://zed.dev/education) - 18歳以上の大学在学生にZed Proを1年間無料で提供します。月$10相当のAIトークンクレジットと無制限のedit predictionが含まれます。作成から30日以上経過したGitHubアカウントと大学のメールアドレスで認証し、1年後はFreeプランに移行します。
- 🎓 [OpenAI Codex Student Credits](https://developers.openai.com/community/students) - OpenAIのコーディングエージェントCodexに使える$100相当(2,500クレジット)のChatGPTクレジットを提供します。発行後12か月有効、1人1回で、米国・カナダ在住の学位課程の大学生がSheerID認証で受け取れます。
- 🎓 [Kiro for Students](https://kiro.dev/students/) - AWSが提供するAIコーディングアシスタントです。コード生成、デバッグ、最適化をサポートし、AWSサービスとの統合が強みです。認証された学校の学生は1年間、毎月1,000クレジットを無料で受け取れます。現在は米国内の11大学から順次展開しており、対象校でない場合は[Waitlist](https://kiro.dev/students/#request)に登録できます。
- 🆓 [Continue.dev](https://www.continue.dev/) - オープンソースのAIコーディングアシスタントで、VS CodeとJetBrains IDEをサポートします。自分のAPIキーを接続すれば様々なLLMを無制限に利用できるため、コストを抑えてAIコーディングを活用したい学生に適しています。

## AIアシスタント・教育プラン

- 🎓 [ChatGPT Edu](https://openai.com/chatgpt/education/) - OpenAIのChatGPT Eduは大学・高等教育機関向けに設計されています。学生・教職員にGPT-4oへのアクセス、エンタープライズレベルのセキュリティ、高いメッセージ上限、データ分析・チュータリング・研究支援ツールを提供します。教育機関は手頃な価格でキャンパス全体に展開できます。
- 🎓 [Claude for Education](https://www.anthropic.com/education) - AnthropicのClaude for Educationは、高等教育に特化したClaudeを提供します。ガイド付き学習のためのLearning mode、学生プロジェクト向けのAPIクレジット、多数の大学とのパートナーシップが含まれます。教育機関はAnthropicに連絡してキャンパス全体のアクセスをリクエストできます。
- 🎓 [Gemini for Students](https://gemini.google/students/) - Googleは対象の大学生にGoogle One AI Premium(Gemini Advancedを含む)を最大12〜15か月間無料で提供します。最新モデルベースのGemini Advanced、2TBのストレージ、NotebookLM Plus、Deep Researchなどのツールが含まれます。SheerIDによる在学認証が必要です。
- 🎓 [Perplexity Education Pro](https://www.perplexity.ai/students) - 大学以上の在学生・教職員にPerplexity Proを50%割引($10/月)で提供します。Learn Modeなどの教育機能が含まれ、SheerIDで認証します。
- 🆓 [StudyArena](https://studyarena.com) - 学習の質問に対する三つのモデルの回答を匿名で比較し、投票後にモデル名を確認できる無料ツールです。学生認証は不要です。モデルの選択と六つの回答の比較には有料のSupporterが必要です。

## 開発ツール

- 🆓 [Visual Studio Community](https://visualstudio.microsoft.com/vs/community/) - Microsoftが提供する無料の統合開発環境(IDE)です。学生、オープンソースコントリビューター、個人開発者が無料で利用でき、GitHub Student Developer Packを通じてVisual Studio Enterpriseの1年間無料特典も提供されます。
- 🎓 [JetBrains 無料教育ライセンス](https://www.jetbrains.com/community/education/#students) - JetBrainsは学生にIntelliJ IDEA、PyCharm、PhpStormなどのプロフェッショナル開発ツールを無料で提供しています。学校のメールアドレスで認証すると1年間のライセンスが取得でき、在学中は何度でも更新できます。
- 🎓 [GitHub Student Developer Pack](https://education.github.com/pack) - 学生向けに10万ドル以上の価値がある開発ツール・サービスのパックです。GitHub Pro、GitHub Copilot、JetBrains IDE、Canvaなどが含まれます。13歳以上の学生が申請できます。
- 🎓 [Unity Student Plan](https://unity.com/products/unity-student) - Unityは学生にゲーム開発プラットフォームUnity Proへの無料アクセスを提供しています。リアルタイムレンダリング、マルチプレイヤーなどの機能が含まれます。
- 🆓 [Unreal Engine for Students](https://www.unrealengine.com/en-US/students) - Epic Gamesが提供するプログラムで、学生は教育目的でUnreal Engineを無料で利用できます。ゲーム開発の学習、プロジェクト制作、インタラクティブ体験の構築などに活用できます。
- 🆓 [Docker Desktop](https://www.docker.com/products/docker-desktop/) - Docker Desktopは個人ユーザー、学生、小規模チーム(25人未満)に無料で提供されます。コンテナベースの開発環境構築、Docker Hubへのアクセスなどをサポートします。

## クラウド

- 🎓 [AWS Educate](https://aws.amazon.com/education/awseducate/) - Amazon Web Services(AWS)が学生と教育者に、クラウドコンピューティングとAWSサービスを学べるリソースとツールを提供します。AWSクレジット($100)、Starter Account、学習パス、求人掲示板、AWS認定資格の準備などが含まれます。
- 🎓 [Microsoft Azure for Students](https://azure.microsoft.com/en-us/free/students/) - 学生に$100のクレジットとAzureサービスへの12か月間の無料アクセスを提供します。仮想マシン、ストレージ、データベースなど様々なクラウドサービスを利用でき、学校のメールアドレスで認証します。
- 🎓 [Google Cloud for Students](https://cloud.google.com/edu/students) - Googleが学生にGoogle Cloud Platform(GCP)のリソースとサービスへの無料アクセスを提供します。クレジット($50〜$300)、Qwiklabsの無料ハンズオン、コンピューティング、ストレージ、機械学習、データ分析など、クラウド技術を探索・実験できます。

## コラボレーションツール

- 🎓 [Atlassian for Education](https://www.atlassian.com/education) - Atlassianは教育機関にJira、Confluence、Trello、Bitbucketなどの開発・コラボレーションツール製品群への無料アクセスを提供しています。学生は所属教育機関のライセンスを通じてこれらのツールを利用できます。

## デザインツール

- 🎓 [Adobe Creative Cloud for Students](https://www.adobe.com/creativecloud/buy/students.html) - Adobeは認定教育機関に在学中の学生に、Photoshop、Illustrator、Premiere Proなどを含むCreative Cloud製品群を60%割引で提供しています。
- 🎓 [Figma for Education](https://www.figma.com/education/) - 学生や教師であればFigma Professionalプランを無料で利用でき、無制限のチームプロジェクトと月3,000のAIクレジット(Figma Makeなどで使用可能)をサポートします。FigmaとFigJamは、プロのデザイナーやエンジニアが使用するデザイン・コラボレーションソフトウェアです。

## 生産性ツール

- 🎓 [Notion for Students and Educators](https://www.notion.so/students) - Notionはノート作成、タスク管理、Wiki作成など多様な機能を提供するオールインワン生産性ツールです。学生と教育者に無料のPlusプランを提供しており、学校のメールアドレスで登録すると利用できます。
