## 바이브 코딩·AI 앱 빌더

- 🎓 [Replit Student Discount](https://replit.com/edu/students) - 학생에게 Replit Core 플랜을 50% 할인($10/월)으로 제공합니다. 자연어로 앱을 만들고 배포하는 Replit Agent의 AI 크레딧이 포함됩니다. .edu 이메일로 인증합니다.
- 🎓 [Lovable for Students](https://lovable.dev/students) - Lovable Pro 플랜을 최대 12개월간 50% 할인($12.50/월)으로 제공합니다. 전 세계 인가 대학 재학생이 대상이며, 대학 이메일 또는 학생증으로 인증합니다. Free 플랜에서만 활성화할 수 있고, 해지하면 재활성화할 수 없습니다.
- 🎓 [Bolt.new Education Discount](https://bolt.new/education-discount) - 대학·고등교육기관 재학생에게 Bolt Pro 50% 할인을 제공합니다(교사는 Pro 무료). SheerID 인증 후 쿠폰 코드를 발급받으며, K-12는 대상이 아닙니다.
- 🎓 [v0 for Students (Vercel)](https://v0.app/students) - 프롬프트로 풀스택 앱을 생성하는 Vercel의 AI 앱 빌더 v0의 Premium 플랜을 1년간 무료로 제공합니다. 파트너 학교(Stanford, MIT, Berkeley, Georgia Tech, Waterloo 등) 한정이며, 학교 이메일로 가입·인증합니다.

## AI 코딩 도구

- 🆓 [GitHub Copilot Free](https://github.com/features/copilot) - GitHub에서 제공하는 AI 코딩 어시스턴트입니다. 무료 플랜으로 월 2,000회 코드 완성과 제한된 채팅을 이용할 수 있으며, GitHub Student Developer Pack 인증 학생은 GitHub Copilot Student 플랜을 무료로 사용할 수 있습니다.
- 🆓 [Cursor Free Plan](https://www.cursor.com/) - VS Code 기반의 AI 코드 에디터입니다. 무료 Hobby 플랜에서 Auto 모델을 사용한 Agent, Chat, Tab 완성을 제한적으로 이용할 수 있으며 신용카드가 필요 없습니다. 유료 플랜은 월 $20부터 시작합니다.
- 🎓 [Zed Education](https://zed.dev/education) - 만 18세 이상 대학 재학생에게 Zed Pro 1년 무료를 제공합니다. 월 $10 상당의 AI 토큰 크레딧과 무제한 edit prediction이 포함됩니다. 생성 30일 이상 된 GitHub 계정과 대학 이메일로 인증하며, 1년 후 Free 플랜으로 전환됩니다.
- 🎓 [OpenAI Codex Student Credits](https://developers.openai.com/community/students) - OpenAI의 코딩 에이전트 Codex에 사용할 수 있는 $100 상당(2,500 크레딧)의 ChatGPT 크레딧을 제공합니다. 발급 후 12개월 유효, 1인 1회이며, 미국·캐나다 거주 학위과정 대학생이 SheerID로 인증해 받을 수 있습니다.
- 🎓 [Kiro for Students](https://kiro.dev/students/) - AWS에서 제공하는 AI 코딩 에이전트입니다. 코드 생성, 디버깅, 최적화를 지원하며, AWS 서비스와의 통합이 강점입니다. 16개국 132개 대학의 만 18세 이상 학생이 1년간 매달 1,000 크레딧을 무료로 받으며, 프리미엄 모델과 Kiro Web이 포함됩니다. 대학 이메일로 SheerID 인증을 거칩니다.
- 🆓 [Continue.dev](https://www.continue.dev/) - VS Code, JetBrains IDE, CLI를 지원하는 오픈소스 AI 코딩 에이전트입니다. Cursor에 인수되었으며, 오픈소스 코드베이스는 계속 무료로 공개되어 있습니다.
- 🆓 [Google Antigravity](https://antigravity.google/) - 자율 에이전트로 소프트웨어를 만드는 Google의 에이전트 우선 IDE입니다. 무료 개인 플랜에서 Gemini 3 모델, Claude, GPT-OSS를 사용할 수 있으며, 주간 사용량 제한 내에서 Tab 완성과 명령 요청을 무제한으로 이용할 수 있습니다.
- 🆓 [YYLO](https://github.com/yylo-dev/yylo) - AI 코딩 에이전트를 위한 오픈소스 커맨드라인 오케스트레이터입니다. 각 작업은 격리된 브랜치/워크트리에서 실행되며 타입화된 작업·검증·병합 경계를 제공합니다. 누구나 무료(MIT), npm(@yylo/cli)으로 설치할 수 있습니다.

## AI 어시스턴트·교육 플랜

- 🎓 [ChatGPT Edu](https://openai.com/chatgpt/education/) - OpenAI의 ChatGPT Edu는 대학 및 고등 교육 기관을 위해 설계되었습니다. 학생, 교직원에게 OpenAI의 최신 플래그십 모델 접근, 기업 수준의 보안, 높은 메시지 한도, 데이터 분석, 튜터링, 연구 지원 도구를 제공합니다. 기관에서 합리적인 가격으로 캠퍼스 전체에 배포할 수 있습니다.
- 🎓 [Claude for Education](https://www.anthropic.com/education) - Anthropic의 Claude for Education은 고등 교육을 위한 특화된 Claude 버전을 제공합니다. 가이드 학습을 위한 Learning mode, 학생 프로젝트를 위한 API 크레딧, 다수 대학과의 파트너십이 포함됩니다. 기관에서 Anthropic에 연락하여 캠퍼스 전체 접근권을 요청할 수 있습니다.
- 🎓 [Gemini for Students](https://gemini.google/students/) - Google은 미국 외 지역의 자격을 갖춘 학생에게 Google AI Plus를 12개월간 무료로 제공하고, Google AI Pro는 학생 할인가로 제공합니다. Google AI Pro를 YouTube Premium 학생 플랜과 묶어 최대 4년간 이용할 수도 있습니다. 학교 이메일로 SheerID 인증을 거치며, 2026년 12월 31일까지 신청해야 합니다.
- 🎓 [Perplexity Education Pro](https://www.perplexity.ai/students) - 대학 이상 재학생·교직원에게 Perplexity Pro를 50% 할인($10/월)으로 제공합니다. Learn Mode 등 교육 기능이 포함되며, SheerID로 인증합니다.
- 🆓 [StudyArena](https://studyarena.com) - 학습 질문에 대한 세 모델의 답변을 익명으로 비교하고, 투표한 뒤 어떤 모델이었는지 확인할 수 있는 무료 도구입니다. 무료 계정(Google·Apple·Discord·이메일)만 있으면 되고 학생 인증은 필요 없습니다. 모델 직접 선택과 여섯 모델 비교는 유료 Supporter 플랜(월 $20) 기능입니다.

## 개발 도구

- 🆓 [Visual Studio Community](https://visualstudio.microsoft.com/vs/community/) - Microsoft에서 제공하는 무료 통합 개발 환경(IDE)입니다. 학생, 오픈소스 기여자, 개인 개발자가 무료로 사용할 수 있으며, GitHub Student Developer Pack을 통해 Visual Studio Enterprise 1년 무료 혜택도 제공됩니다.
- 🎓 [JetBrains 무료 교육용 라이선스](https://www.jetbrains.com/community/education/#students) - JetBrains는 학생들에게 IntelliJ IDEA, PyCharm, PhpStorm 등 전문 소프트웨어 개발 도구를 무료로 제공합니다. 학교 이메일로 인증하면 1년 라이선스를 받을 수 있으며, 재학 중 무제한 갱신이 가능합니다.
- 🎓 [GitHub Student Developer Pack](https://education.github.com/pack) - 학생을 위한 $100,000 이상 가치의 소프트웨어 개발 도구 및 서비스 모음입니다. GitHub Pro, GitHub Copilot, JetBrains IDE, Canva 등이 포함됩니다. 13세 이상 학생이 신청할 수 있습니다.
- 🎓 [Unity Student Plan](https://unity.com/products/unity-student) - Unity는 학생들에게 Unity Pro 게임 개발 플랫폼에 대한 무료 접근권을 제공합니다. 실시간 렌더링, 멀티플레이어 등의 기능이 포함됩니다.
- 🆓 [Unreal Engine for Students](https://www.unrealengine.com/en-US/students-and-schools) - Epic Games에서 제공하는 프로그램으로, 학생들이 Unreal Engine을 교육 목적으로 무료 사용할 수 있습니다. 게임 개발 학습, 프로젝트 제작, 인터랙티브 경험 구축 등에 활용할 수 있습니다.
- 🆓 [Docker Desktop](https://www.docker.com/products/docker-desktop/) - Docker Desktop은 개인 사용자, 학생·교육자, 소규모 기업(직원 250명 미만이면서 연 매출 $1,000만 미만)에게 무료로 제공됩니다. 컨테이너 기반 개발 환경 구축, Docker Hub 접근 등을 지원합니다.

## 클라우드

- 🆓 [AWS Educate](https://aws.amazon.com/education/awseducate/) - Amazon Web Services(AWS)에서 누구나 무료로 이용할 수 있는 자기 주도형 클라우드 컴퓨팅 강좌, 실습 랩, 디지털 배지를 제공합니다. 만 13세 이상이면 신용카드나 학생 인증 없이 이용할 수 있고, 만 18세 이상은 취업 게시판도 쓸 수 있습니다.
- 🎓 [Microsoft Azure for Students](https://azure.microsoft.com/en-us/free/students/) - 학생들에게 $100 크레딧과 Azure 서비스 12개월 무료 접근을 제공합니다. 가상 머신, 스토리지, 데이터베이스 등 다양한 클라우드 서비스를 이용할 수 있으며, 학교 이메일로 인증합니다.
- 🎓 [Google Cloud for Students](https://cloud.google.com/edu/students) - Google에서 학생들에게 Google Cloud Platform(GCP) 리소스와 서비스에 대한 무료 접근권을 제공합니다. Google Skills 크레딧 200개(발급 후 1년간 유효), Google Skills Arcade의 무료 실습, 스킬 배지, Cloud Certificate 등으로 컴퓨팅, 스토리지, 머신러닝, 데이터 분석을 탐색하고 실험할 수 있습니다.
- 🎓 [MongoDB for Students](https://www.mongodb.com/students) - GitHub Student Developer Pack을 통해 학생에게 MongoDB Atlas 크레딧 $50과 MongoDB 인증(약 $150 상당)을 무료로 제공합니다. 데이터베이스 실력을 쌓고 검증할 수 있습니다.

## 협업 도구

- 🎓 [Atlassian for Education](https://www.atlassian.com/licensing/purchase-licensing) - Atlassian은 교육 기관에 제품별로 할인율이 다른 학술 라이선스(대체로 정가의 50% 할인, Confluence 75% 할인, 일부 제품 최대 100% 할인)를 제공하고, 학생·교사에게 Classroom 라이선스(대부분의 클라우드 앱 75% 할인, Bitbucket Cloud Standard 무료)를 제공합니다. 최대 10명까지 사용 가능한 무료 플랜도 누구나 이용할 수 있습니다.

## 디자인 도구

- 🎓 [Adobe Creative Cloud for Students](https://www.adobe.com/creativecloud/buy/students.html) - Adobe는 학생과 교사에게 Photoshop, Illustrator, Premiere Pro 등이 포함된 Creative Cloud Pro를 첫 1년간 71% 할인된 월 US$19.99(정가 US$69.99)에 제공하며, 이후에는 월 US$39.99입니다. 인증된 교육 기관 재학생이 대상입니다.
- 🎓 [Figma for Education](https://www.figma.com/education/) - 학생이나 교사라면 Figma Professional 플랜을 무료로 사용할 수 있으며, 무제한 팀 프로젝트와 월 3,000 AI 크레딧(Figma Make 등에 사용 가능)을 지원합니다. Figma와 FigJam은 전문 디자이너, 엔지니어 등이 사용하는 디자인 및 협업 소프트웨어입니다.

## 생산성 도구

- 🎓 [Notion for Students and Educators](https://www.notion.so/students) - Notion은 노트 작성, 작업 관리, 위키 생성 등 다양한 기능을 제공하는 종합 생산성 도구입니다. 학생과 교육자에게 무료 Plus 플랜을 제공하며, 학교 이메일로 가입하면 이용할 수 있습니다.

## 기여하기

기여를 환영합니다! 항목을 추가할 때는:

- `- 🎓 [프로그램명](URL) - 설명` 형식을 사용합니다 (학생·교육기관 인증이 필요하면 🎓, 누구나 무료면 🆓).
- 공식 페이지를 기준으로 혜택의 구체적 내용(할인율, 크레딧 금액, 기간)과 자격·인증 방법을 포함합니다.
- 성격에 맞는 기존 섹션에 배치하고, 맞는 섹션이 없을 때만 새 섹션을 추가합니다.
- 세 언어 파일을 모두 갱신합니다: `README.md`(영어), `README.ko.md`(한국어), `README.ja.md`(일본어).
