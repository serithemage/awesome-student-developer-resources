## 바이브 코딩·AI 앱 빌더

- 🎓 [Replit Student Discount](https://replit.com/edu/students) - 학생에게 Replit Core 플랜을 50% 할인($10/월)으로 제공합니다. 자연어로 앱을 만들고 배포하는 Replit Agent의 AI 크레딧이 포함됩니다. .edu 이메일로 인증합니다. 한국 신청: 확인 불가 — 공식 페이지는 .edu 이메일만 요구하고 국가 목록을 밝히지 않아 .ac.kr 등 국내 기관 도메인 인정 여부가 확인되지 않습니다.
- 🎓 [Lovable for Students](https://lovable.dev/students) - Lovable Pro 플랜을 최대 12개월간 50% 할인($12.50/월)으로 제공합니다. 전 세계 인가 대학 재학생이 대상이며, 대학 이메일 또는 학생증으로 인증합니다. Free 플랜에서만 활성화할 수 있고, 해지하면 재활성화할 수 없습니다. 한국 신청: 확인 불가 — 학교 발급 이메일이 필요하지만 공식 페이지에 대상 국가·현지 가격·기한이 없어 국내 신청 자격이 확인되지 않습니다.
- 🎓 [Bolt.new Education Discount](https://bolt.new/education-discount) - 대학·고등교육기관 재학생에게 Bolt Pro 50% 할인을 제공합니다(교사는 Pro 무료). SheerID 인증 후 쿠폰 코드를 발급받으며, K-12는 대상이 아닙니다. 한국 신청: 확인 불가 — 대학·고등교육 재학과 SheerID 인증은 확인되지만 대상 국가 목록이 없어 국내 자격·가격이 확인되지 않습니다.
- 🎓 [v0 for Students (Vercel)](https://v0.app/students) - 프롬프트로 풀스택 앱을 생성하는 Vercel의 AI 앱 빌더 v0의 Premium 플랜을 1년간 무료로 제공합니다. 파트너 학교(Stanford, MIT, Berkeley, Georgia Tech, Waterloo 등) 한정이며, 학교 이메일로 가입·인증합니다. 한국 신청: 불가 — 공식 대상 학교 목록에 국내 대학이 없고 추가 예정 안내만 있습니다([대상 학교](https://v0.app/students)).
- 🎓 [Bleenk](https://www.bleenk.app/en/students) - 학생·교육자 인증을 마치면 Bleenk 전체 기능을 무료로 이용할 수 있습니다. AI 에이전트 코딩, 샌드박스 테스트, Vercel·Netlify 배포, 무제한 로컬 프로젝트, GitHub 연동이 포함되며 신용카드가 필요 없습니다. 고등학교·대학 재학과 .edu 또는 학교 인증 이메일, 재학 증빙이 필요합니다. 한국 신청: 확인 불가 — .edu 또는 학교 인증 이메일이 필요하지만 국가 목록이 없어 국내 기관 이메일 인정 여부가 확인되지 않습니다.

## AI 코딩 도구

- 🆓 [GitHub Copilot Free](https://github.com/features/copilot) - GitHub에서 제공하는 AI 코딩 어시스턴트입니다. 무료 플랜으로 월 2,000회 코드 완성과 제한된 채팅을 이용할 수 있으며, GitHub Student Developer Pack 인증 학생은 GitHub Copilot Student 플랜을 무료로 사용할 수 있습니다.
- 🆓 [Cursor Free Plan](https://www.cursor.com/) - VS Code 기반의 AI 코드 에디터입니다. 무료 $0 플랜에서 AI 사용량과 Agent·Chat 요청을 제한적으로 이용할 수 있으며 신용카드가 필요 없습니다. 유료 플랜은 Plus 월 $8, Premium 월 $30, Super 월 $100, Ultra 월 $200입니다.
- 🎓 [Zed Education](https://zed.dev/education) - 만 18세 이상 대학 재학생에게 Zed Pro 1년 무료를 제공합니다. 월 $10 상당의 AI 토큰 크레딧과 무제한 edit prediction이 포함됩니다. 생성 30일 이상 된 GitHub 계정과 대학 이메일로 인증하며, 1년 후 Free 플랜으로 전환됩니다. 한국 신청: 가능 — 전 세계 인가 대학 재학생이 대상이며 만 18세 이상, 생성 30일 이상 GitHub 계정, 대학 이메일 조건을 충족해야 합니다([공식 안내](https://zed.dev/education)).
- 🎓 [OpenAI Codex Student Credits](https://developers.openai.com/community/students) - OpenAI의 코딩 에이전트 Codex에 사용할 수 있는 $100 상당(2,500 크레딧)의 ChatGPT 크레딧을 제공합니다. 발급 후 12개월 유효, 1인 1회이며, 미국·캐나다 거주 학위과정 대학생이 인증해 받을 수 있습니다. 한국 신청: 불가 — 미국·캐나다 소재 학위 수여 대학 재학생이 대상이고 청구 시 미국·캐나다 거주가 필요합니다([공식 안내](https://developers.openai.com/community/students)).
- 🎓 [Kiro for Students](https://kiro.dev/students/) - AWS에서 제공하는 AI 코딩 에이전트입니다. 코드 생성, 디버깅, 최적화를 지원하며, AWS 서비스와의 통합이 강점입니다. 16개국 132개 대학의 만 18세 이상 학생이 1년간 매달 1,000 크레딧을 무료로 받으며, 프리미엄 모델과 Kiro Web이 포함됩니다. 대학 이메일로 SheerID 인증을 거칩니다. 한국 신청: 가능 — 공식 대상 학교 목록에 국민대학교, 서울대학교, 연세대학교가 포함되며, 해당 대학 재학생이 대학 이메일로 인증해야 합니다([대상 학교](https://kiro.dev/students/)).
- 🆓 [Continue.dev](https://www.continue.dev/) - VS Code, JetBrains IDE, CLI를 지원하는 오픈소스 AI 코딩 에이전트입니다. Cursor에 인수되었으며, 오픈소스 코드베이스는 계속 무료로 공개되어 있습니다.
- 🆓 [Google Antigravity](https://antigravity.google/) - 자율 에이전트로 소프트웨어를 만드는 Google의 에이전트 우선 IDE입니다. 무료 개인 플랜에서 Gemini 3 모델, Claude, GPT-OSS를 사용할 수 있으며, 주간 사용량 제한 내에서 Tab 완성과 명령 요청을 무제한으로 이용할 수 있습니다.

## AI 어시스턴트·교육 플랜

- 🎓 [ChatGPT Edu](https://openai.com/chatgpt/education/) - OpenAI의 ChatGPT Edu는 대학 및 고등 교육 기관을 위해 설계되었습니다. 학생, 교직원에게 OpenAI의 최신 플래그십 모델 접근, 기업 수준의 보안, 높은 메시지 한도, 데이터 분석, 튜터링, 연구 지원 도구를 제공합니다. 기관에서 합리적인 가격으로 캠퍼스 전체에 배포할 수 있습니다. 한국 신청: 조건부 — 국내 대학이 ChatGPT Edu를 도입해야 하며 학생 개인은 구매할 수 없습니다. 한국은 ChatGPT 지원 국가이지만 국내 도입 대학 목록과 현지 가격은 공개되지 않았습니다([ChatGPT Edu](https://openai.com/chatgpt/education/), [지원 국가](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)).
- 🎓 [Claude for Education](https://www.anthropic.com/education) - Anthropic의 Claude for Education은 고등 교육을 위한 특화된 Claude 버전을 제공합니다. 가이드 학습을 위한 Learning mode, 학생 프로젝트를 위한 API 크레딧, 다수 대학과의 파트너십이 포함됩니다. 기관에서 Anthropic에 연락하여 캠퍼스 전체 접근권을 요청할 수 있습니다. 한국 신청: 조건부 — 국내 대학이 Anthropic과 캠퍼스 계약을 맺어야 하며 학생 개인 신청은 불가합니다. 공식 자료에 국내 파트너 대학이 없어 소속 대학에 확인해야 합니다([Claude for Education](https://www.anthropic.com/education)).
- 🎓 [Gemini for Students](https://gemini.google/students/) - Google은 한국과 일본의 만 18세 이상 대학생에게 Google AI Plus Student 플랜을 12개월간 무료로 제공합니다. Gemini 사용량 2배, 400GB 저장공간, Gemini Omni, 학습 노트북, 인터랙티브 시각화, 무제한 업로드, Gemini Live가 포함됩니다. 결제수단을 등록해야 하며, 무료 기간이 끝나면 해지하지 않는 한 한국은 월 ₩7,500, 일본은 월 ¥725로 자동 갱신됩니다. 미국에서는 무료 학생 혜택이 Google AI Pro 1년으로 제공됩니다. 자격은 매년 다시 인증해야 하고, 2026년 12월 31일까지 신청해야 합니다. 한국 신청: 가능 — 만 18세 이상 대학생이 결제수단을 등록하고 2026년 12월 31일까지 신청하면 1년간 무료로 이용할 수 있으며, 이후 월 ₩7,500이 자동 결제됩니다([한국 공식 페이지](https://gemini.google/kr/students/)).
- 🎓 [Perplexity Education Pro](https://www.perplexity.ai/students) - 대학 이상 재학생·교직원에게 Perplexity Pro를 50% 할인($10/월)으로 제공합니다. Learn Mode 등 교육 기능이 포함되며, SheerID로 인증합니다. 한국 신청: 확인 불가 — SheerID 인증과 할인가는 확인되지만 공식 페이지에 대상 국가·현지 통화·가격이 없습니다.
- 🆓 [StudyArena](https://studyarena.com) - 학습 질문에 대한 세 모델의 답변을 익명으로 비교하고, 투표한 뒤 어떤 모델이었는지 확인할 수 있는 무료 도구입니다. 무료 계정(Google·Apple·Discord·이메일)만 있으면 되고 학생 인증은 필요 없습니다. 모델 직접 선택과 여섯 모델 비교는 유료 Supporter 플랜(월 $20) 기능입니다.

## 개발 도구

- 🆓 [Visual Studio Community](https://visualstudio.microsoft.com/vs/community/) - Microsoft에서 제공하는 무료 통합 개발 환경(IDE)입니다. 학생, 오픈소스 기여자, 개인 개발자가 무료로 사용할 수 있으며, GitHub Student Developer Pack을 통해 Visual Studio Enterprise 1년 무료 혜택도 제공됩니다.
- 🎓 [JetBrains 무료 교육용 라이선스](https://www.jetbrains.com/community/education/#students) - JetBrains는 학생들에게 IntelliJ IDEA, PyCharm, PhpStorm 등 전문 소프트웨어 개발 도구를 무료로 제공합니다. 학교 이메일로 인증하면 1년 라이선스를 받을 수 있으며, 재학 중 무제한 갱신이 가능합니다. 한국 신청: 확인 불가 — 인정 교육기관 재학·재직이 필요하고 신청 방식이 지역별로 다르다고만 안내되어 국내 신청 경로가 확인되지 않습니다.
- 🎓 [GitHub Student Developer Pack](https://education.github.com/pack) - 학생을 위한 $100,000 이상 가치의 소프트웨어 개발 도구 및 서비스 모음입니다. GitHub Pro, GitHub Copilot, JetBrains IDE, Canva 등이 포함됩니다. 13세 이상 학생이 신청할 수 있습니다. 한국 신청: 확인 불가 — 학위·졸업장 과정 재학 증빙과 만 13세 이상 조건은 확인되지만 국가 목록이 없어 국내 학교·이메일 인정 여부가 확인되지 않습니다.
- 🎓 [Unity Student Plan](https://unity.com/products/unity-student) - Unity는 학생들에게 Unity Pro 게임 개발 플랫폼에 대한 무료 접근권을 제공합니다. 실시간 렌더링, 멀티플레이어 등의 기능이 포함됩니다. 한국 신청: 확인 불가 — 만 16세 이상 인정 교육기관 재학생이 SheerID로 인증하는 조건은 확인되지만 대상 국가 목록은 없습니다.
- 🆓 [Unreal Engine for Students](https://www.unrealengine.com/en-US/students-and-schools) - Epic Games에서 제공하는 프로그램으로, 학생들이 Unreal Engine을 교육 목적으로 무료 사용할 수 있습니다. 게임 개발 학습, 프로젝트 제작, 인터랙티브 경험 구축 등에 활용할 수 있습니다. 한국 신청: 확인 불가 — 학생·학교의 교육 목적 무료 사용은 안내되어 있으나 국가별 조건은 명시되지 않았습니다.
- 🆓 [Docker Desktop](https://www.docker.com/products/docker-desktop/) - Docker Desktop은 개인 사용자, 학생·교육자, 소규모 기업(직원 250명 미만이면서 연 매출 $1,000만 미만)에게 무료로 제공됩니다. 컨테이너 기반 개발 환경 구축, Docker Hub 접근 등을 지원합니다.

## 클라우드

- 🆓 [AWS Educate](https://aws.amazon.com/education/awseducate/) - Amazon Web Services(AWS)에서 누구나 무료로 이용할 수 있는 자기 주도형 클라우드 컴퓨팅 강좌, 실습 랩, 디지털 배지를 제공합니다. 만 13세 이상이면 신용카드나 학생 인증 없이 이용할 수 있고, 만 18세 이상은 취업 게시판도 쓸 수 있습니다. 한국 신청: 확인 불가 — 만 13세 이상이면 이메일로 가입할 수 있다는 안내만 있고 국가 목록이나 국내 전용 조건은 없습니다.
- 🎓 [Microsoft Azure for Students](https://azure.microsoft.com/en-us/free/students/) - 학생들에게 $100 크레딧과 Azure 서비스 12개월 무료 접근을 제공합니다. 가상 머신, 스토리지, 데이터베이스 등 다양한 클라우드 서비스를 이용할 수 있으며, 학교 이메일로 인증합니다. 한국 신청: 확인 불가 — 만 18세 이상 정규 학위과정 재학생이 기관 이메일로 인증해야 한다는 조건은 확인되지만 대상 국가 목록이 없어 국내 가격·통화는 확인되지 않습니다.
- 🎓 [Google Cloud for Students](https://cloud.google.com/edu/students) - Google에서 학생들에게 Google Cloud Platform(GCP) 리소스와 서비스에 대한 무료 접근권을 제공합니다. Google Skills 크레딧 200개(발급 후 1년간 유효), Google Skills Arcade의 무료 실습, 스킬 배지, Cloud Certificate 등으로 컴퓨팅, 스토리지, 머신러닝, 데이터 분석을 탐색하고 실험할 수 있습니다. 한국 신청: 가능 — 공식 지원 국가 목록에 한국이 포함되며, 지역 인가 비영리 기관 재학생이 인증을 완료해야 합니다([지원 국가](https://support.google.com/google-cloud-higher-ed/answer/10322652?hl=en), [학생 프로그램](https://cloud.google.com/edu/students)).
